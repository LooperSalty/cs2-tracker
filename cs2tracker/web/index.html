Evenements

    Anti-triche

    Un score de suspicion explicable, calcule sur des donnees publiques. Ce n'est pas une preuve : seul Valve peut trancher.

    En partie classique, CS2 ne transmet que ton propre etat. Pour analyser les dix joueurs : ouvre la console avec ~, tape status, puis colle toute la sortie ici. Le format exact n'a pas d'importance.

    Ecart a la population

    Chaque point est un indicateur. Sa distance au centre est son ecart-type par rapport a un joueur moyen ; sa direction indique la famille d'indicateurs. Un profil ordinaire reste groupe au centre.

    Configuration

    Cle API Steam, liaison avec le jeu et diagnostic de l'installation.

    Cle API Steam

    Necessaire pour lire les profils et les statistiques. Elle s'obtient gratuitement sur steamcommunity.com/dev/apikey. Elle est stockee dans le fichier .env local et n'est envoyee qu'a Steam.

    Liaison temps reel

    Ecrit gamestate_integration_cs2tracker.cfg dans le dossier de configuration de CS2. C'est le mecanisme officiel de Valve : le jeu pousse son etat vers cette application. Redemarre CS2 apres l'installation.
